## 讨论问题与参考答案

### 1. SHA-256 在这个项目中起什么作用？它是不是加密？

参考答案：SHA-256 将输入内容计算成固定长度的 256 位摘要。本项目用它生成区块哈希。它属于哈希算法，不等同于加密；通常不能通过哈希值直接还原原始内容。

### 2. 为什么每个新区块要保存上一个区块的哈希？

参考答案：前序哈希把新区块和上一个区块连接起来。若旧区块内容被修改，重新计算得到的哈希会变化，后续区块保存的前序哈希就可能对不上，因此可以发现数据或连接关系异常。

### 3. 只使用哈希连接，是否就构成完整的去中心化区块链？

参考答案：不是。本项目只有单机内存中的区块列表和哈希连接，没有点对点网络、多个节点、共识机制、数字签名等功能。它只是帮助理解哈希链的入门演示。

### 4. 本项目为什么选择 Java，而不是直接使用复杂的区块链框架？

参考答案：Java 是常见的大学课程语言，类、对象、集合和异常处理都能在项目中得到练习。直接使用大型框架会隐藏区块和哈希连接的细节，不利于初学者理解核心流程。

### 5. MIT 许可证允许别人做什么？使用时有什么要求？

参考答案：MIT 许可证允许他人使用、复制、修改、合并、发布、分发、再许可和销售软件副本，但需要在软件副本或重要部分中保留版权声明和许可声明。软件按“现状”提供，不作担保。具体以 LICENSE 文件为准。

### 6. 为什么使用分支和 Pull Request，而不是直接修改 main 分支？

参考答案：分支可以隔离不同功能的修改，避免未完成内容影响主分支。Pull Request 让同学先查看改动、提出建议并讨论，确认没有明显问题后再合并，也保留协作记录。

### 7. GitHub 的 Star 和 Watch 有什么区别？

参考答案：Star 主要用于收藏或表达对项目的关注；Watch 用于选择是否接收仓库更新通知。两者用途不同，都不能代替实际代码贡献或讨论。
