# 项目分析：华为“五看三定”方法

## 一、五看分析

### 1. 看行业与趋势

区块链的基础研究和应用都离不开数据完整性、可追溯性和可信记录等概念。哈希函数是理解区块连接和数据校验的重要基础。本项目选择从 SHA-256 和前序哈希入手，避免一开始就引入复杂的共识算法或网络架构。

### 2. 看市场与客户

主要使用者是区块链专业或计算机相关专业的初学者，以及需要课堂演示的教师。使用者希望快速运行程序、看懂区块字段，并能通过简单实验观察数据修改前后的验证结果。因此项目采用命令行交互、中文说明和无第三方依赖的设计。

### 3. 看竞争

网上已有区块链浏览器、课程示例和综合开发框架。它们可能功能更完整，但部分工具需要网络、复杂配置或较多先修知识。本项目不与成熟产品竞争，而是定位为小型教学样例，优势在于代码短、结构清楚、容易修改；不足是功能和应用范围有限。

### 4. 看自己

优势：使用常见的 Java 语言；利用标准库完成 SHA-256；代码拆分为 Block、Blockchain 和 Main，便于理解；有基础测试和中文文档。

不足：只在单机内存中运行；没有数据库、网络通信、共识机制、数字签名和权限管理；目前适合学习演示，不适合真实业务。

### 5. 看机会

可作为课程实验或开源入门项目，帮助同学练习 Java 面向对象、Git 分支协作、Issue 讨论和许可证使用。后续可在不破坏入门定位的前提下，增加 Merkle 树、区块数据导入导出、图形界面或简单的多节点模拟。

## 二、三定分析

### 1. 定战略控制点

- 易运行：JDK 8 及以上即可编译，不依赖第三方库。
- 易理解：重点展示区块数据、SHA-256 和前序哈希之间的关系。
- 可验证：提供正常添加、空数据拒绝和数据篡改检测等测试。
- 可协作：通过 README、LICENSE、CONTRIBUTING、Issue、分支和 Pull Request 展示开源协作流程。

### 2. 定目标

- 项目能在 JDK 8 或更高版本正常编译运行。
- 用户可以添加区块、查看区块和验证哈希链。
- 提供至少 4 项基础测试，测试全部通过。
- GitHub 仓库包含 README、MIT LICENSE、贡献指南和项目分析文档。
- 通过至少一次功能分支合并，并与同学完成至少一次 Issue 讨论。

### 3. 定策略

项目采取“小功能、易理解、逐步完善”的策略。第一阶段只实现区块创建、哈希计算、哈希连接和完整性检查；第二阶段补充 README、许可证、贡献指南和测试；第三阶段通过 GitHub 分支、Pull Request 和 Issue 让同学参与评审。保持 MIT 许可证和清晰的贡献流程，鼓励学习和二次修改。

## 三、总结

“五看”帮助明确项目所处的行业背景、目标使用者、同类工具、项目自身能力和发展机会；“三定”进一步把分析转化为控制重点、可检查的目标和实施策略。对于课程项目，最重要的是范围合理、运行可靠、说明清楚并能展示真实的开源协作过程。
